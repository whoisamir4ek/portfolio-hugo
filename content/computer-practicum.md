## Тема 1 · Сайт-портфолио на Hugo

Для первой практической работы создан статический сайт-портфолио на Hugo. Контент размечен в Markdown, оформление вынесено в CSS, а публикация подготовлена для GitHub Pages.

### Что сделано

1. Подготовлена структура страниц: главная, «Об авторе» и раздел компьютерного практикума.
2. Добавлены учебные работы и ссылки на опубликованные отчёты из портфолио первого курса.
3. Настроена автоматическая сборка Hugo и публикация через GitHub Actions.

### Используемые технологии

Hugo · Markdown · HTML · CSS · GitHub Pages · GitHub Actions

### Материалы проекта

- Исходный код: [репозиторий GitHub](https://github.com/whoisamir4ek/portfolio-hugo)
- Развёрнутая версия: [сайт на GitHub Pages](https://whoisamir4ek.github.io/portfolio-hugo/)
- Автоматизация: [workflow публикации](https://github.com/whoisamir4ek/portfolio-hugo/blob/main/.github/workflows/hugo.yaml)

### Как работает публикация

При отправке изменений в ветку `main` GitHub Actions устанавливает Hugo, собирает страницы в каталог `public/`, передаёт результат в GitHub Pages и публикует сайт. Сборка запускается также вручную из вкладки Actions.
