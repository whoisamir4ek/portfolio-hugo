# Портфолио Амира Аглиуллина

Статический сайт учебного портфолио на Hugo для курса «Компьютерный практикум» РГПУ им. А. И. Герцена.

## Локальный запуск

```sh
hugo server
```

## Сборка

```sh
hugo --minify
```

Готовый сайт появится в `public/`.

## Публикация

Workflow `.github/workflows/hugo.yaml` собирает Hugo при отправке изменений в `main` и разворачивает каталог `public/` в GitHub Pages. Для репозитория нужно выбрать **Settings → Pages → GitHub Actions**.
